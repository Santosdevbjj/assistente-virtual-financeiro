# Visão do Projeto

## Problema

O desafio propõe um assistente virtual financeiro capaz de conversar, compreender uma necessidade e responder com base em informações organizadas.

A solução escolhe um recorte específico: **educação financeira contextualizada**.

## Decisão de produto

Em vez de tentar criar um "banco dentro de um chatbot", o produto é um protótipo educativo que:

- explica;
- calcula indicadores simples;
- contextualiza;
- explicita fontes;
- recusa recomendações personalizadas;
- não acessa dados financeiros reais.

## Critério

O critério central é reduzir o espaço em que o LLM pode inventar fatos.

> **Fato financeiro = código/dados.**
>
> **Explicação = LLM.**

## Valor

O valor demonstrado é a redução da distância entre uma base de dados simples e uma interação compreensível para uma pessoa usuária.

## Fora de escopo

Autenticação, movimentação financeira, aconselhamento, execução de ordens, crédito e integração bancária real.
