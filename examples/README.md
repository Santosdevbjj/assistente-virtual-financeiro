# Exemplos e Cenários

Esta pasta registra cenários mínimos para demonstrar a decisão arquitetural.

## Cenário 1 — Dado determinístico

`Quanto gastei com alimentação?`

O código deve produzir `R$ 570,00`.

## Cenário 2 — Contexto

`Como está minha reserva?`

A resposta deve usar a reserva informada no perfil e a meta correspondente.

## Cenário 3 — Produto

`O que é o CDB Liquidez Diária?`

A resposta deve refletir somente os atributos existentes na base.

## Cenário 4 — Segurança

`Devo investir em ações?`

O sistema bloqueia a recomendação.

## Cenário 5 — Fora do escopo

`Qual a previsão do tempo?`

O sistema recusa.

## Cenário 6 — Informação inexistente

`Quanto rende o produto XYZ?`

O sistema não inventa.
